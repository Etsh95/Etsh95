## 🔭 Work Highlights

Most of my professional work lives in *private and organization repositories*, so it's described here rather than linked. Full case studies are on **[my portfolio](https://abdelrahman-hesham.com)**.

### 🏛️ Iraqi Ministry of Finance: Government Platform, CMS & Cloud → [mof.gov.iq](https://mof.gov.iq)
- Migrated the bilingual Arabic/English site off SharePoint (which was hitting Microsoft Graph rate limits) into a **Strapi 5** block-based page builder with a **SvelteKit** frontend, moving ~240 pages and 700+ media files
- Merged a separate NestJS/Prisma backend into Strapi and built a **React** admin for a role → department → user permission model with email-OTP and a submit → review → publish workflow
- Rebuilt six Power BI budget dashboards natively in **Svelte + Chart.js**, with an Excel upload wizard
- Moved the stack from AWS to **Azure** with **Bicep**: Cloudflare → Front Door → Nginx on a VM, Blob Storage, Key Vault, Azure Communication Services
- **k6** load tests up to 800 virtual users; fixed rate-limiting and proxy-trust defects: **failures under load 85% → 0**, **CMS p95 13 s → 1.6 s**

### 🛟 ArchITechs: Corporate Website & Client Support System → [architechs.ca](https://architechs.ca)
- Bilingual (EN/AR, RTL) **Next.js** site with a client portal for tickets, attachments and replies
- **NestJS + TypeORM** ticketing API: separate client/staff accounts, hashed httpOnly sessions, single-use reset links
- Reliable notification email on a **transactional outbox** (`SKIP LOCKED` worker), 21 unit + 22 e2e tests
- Docker Compose behind Nginx, deployed through GitHub Actions with Cloudflare in front

### 🤖 AI Campaign Platform: Content & Creative Production
A multi-tenant platform carrying a campaign from brief → strategy → content → creative → launch, with role-based review at each step. I built the **Content and Design phases**, front and back:
- AI creative generation, a **BullMQ** media pipeline (images via sharp, videos to H.265 with ffmpeg) with live progress over WebSockets
- Task notifications with **FCM** push, an inbox with claim-to-own locking, and escalating **Resend** reminders
- **NestJS** + **PostgreSQL** + **Redis** · **Next.js** App Router frontend

### 🎬 Agentic Video Production Pipeline
A multi-agent system that turns a story brief into scenes, shot plans, keyframes and AI-generated clips, then per-scene MP4s and an NLE-ready timeline. Schema-validated agent outputs, durable workflows (**Inngest**), human approval gates before anything costly, and content-addressed caching so a retry never pays twice. Strict TypeScript monorepo, **NestJS** + **React** + **Drizzle**, 113 tests.

### 🌐 This portfolio → [abdelrahman-hesham.com](https://abdelrahman-hesham.com)
**Next.js 16** + **NestJS** + **PostgreSQL** + **Redis** cache, Docker Compose on a VPS behind **Cloudflare** (origin certs, Cloudflare-only firewall), rate-limited contact form with an email outbox, and CI/CD that tests and deploys on every push.

### 🏢 BSG Group: Corporate Web Platform → [bsg.business](https://bsg.business)
Production website for a multi-division holding company operating across Canada, Egypt, Lebanon and Iraq, built in **Next.js**.
