## 🔭 Work Highlights

Most of my **professional contributions** (features, bug fixes, tests, refactoring) live in *private and organization repositories*, so the work below is described rather than linked.

### 🤖 AI Campaign Platform — Content & Creative Production
An AI-driven marketing platform carrying a campaign from strategy → content → creative → approval → launch. I built the **Content and Design phases**, front and back:
- AI creative generation with **Gemini**, CDN-backed asset delivery, and seven ad-format templates
- Asynchronous design generation via a **BullMQ** queue on **Redis**, processed by a background worker
- Notification system with **FCM** browser push and **Resend** email reminders on a recurring schedule
- **NestJS** (Fastify) + **Prisma** + **PostgreSQL**, hexagonal Clean Architecture · **Next.js** App Router frontend

### 🏛️ Iraq Ministry of Finance — Government Web Platform
Contributed to the system design and delivery of a trilingual (Arabic / English / Kurdish) platform, migrated off SharePoint after it hit Microsoft Graph rate limits:
- Containerized with **Docker Compose** — Svelte, Strapi, and Redis — on **EC2** behind **Nginx**
- AWS provisioned as code with **CloudFormation** (IAM, VPC, ACM), instance access via SSM
- **RDS (PostgreSQL)** + **S3/CloudFront** for documents and media
- Self-managed authentication (OAuth2 + email-OTP) with role-based access control

### 🏢 BSG Group — Corporate Web Platform
Built and shipped the production website for a multi-division holding company operating across Canada, Egypt, Lebanon, and Iraq. Built in **Next.js**. → [bsg.business](https://bsg.business)
